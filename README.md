# Автор: Казаченко Константин
## Описание

Это графическое приложение для планирования тренировок. Позволяет добавлять тренировки, фильтровать их по типу и дате, сохранять и загружать данные.

## Как запустить

1. Убедитесь, что установлен Python 3.x.
2. Скачайте или склонируйте репозиторий.
3. Запустите файл `main.py` командой:
```bash
python main.py
